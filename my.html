    내가 올린 앱

    AI에게 게임 만들어 달라고 할 때

    아래 글을 맨 앞에 붙여서 요청하면 갤러리에서 점수·수료증·태블릿 조작이 잘 돼요.

    글 보기 
    아래 조건을 지켜서 게임을 만들어 줘.

1. 파일 하나로 끝나는 HTML 게임(HTML, CSS, JavaScript를 한 파일에)으로 만들어 줘.
2. 태블릿에서 손가락으로 할 수 있어야 해. 키보드가 없어도 되도록 화면에 조작 버튼을 넣거나 터치·드래그로 움직이게 해 줘. 화면 크기에 맞게 크기가 자동으로 조절되고, 가로·세로 화면 모두에서 잘리지 않게 해 줘.
3. 게임이 한 판 끝날 때마다(성공이든 실패든) 점수를 한 번만 갤러리에 보고하는 아래 한 줄을 꼭 넣어 줘. 점수는 숫자여야 해.
   if (window.GallerySDK) GallerySDK.reportScore('my-game', 점수);
4. 인터넷으로 데이터를 보내거나 받는 코드(fetch, 서버, Firebase 등)는 쓰지 마. 외부 주소는 Tailwind CDN, cdnjs, jsDelivr, Google Fonts만 써도 돼.
5. 이름이나 개인정보를 입력받는 칸은 만들지 마. (별명이 필요하면 "별명(실명 금지)"이라고 써 줘.)
6. 점수를 올리기 쉽게 속여서 만들지 말고, 열심히 할수록 점수가 높아지게 만들어 줘.

(여기에 만들고 싶은 게임 설명을 써요)
