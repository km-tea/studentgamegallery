# 우리 반 웹앱 갤러리

학생이 직접 가입하고, 자기가 만든 웹앱(HTML 파일 1개)을 올리고, 선생님이 확인해서 공개하는 갤러리예요.
**GitHub → Netlify(화면 + 서버 함수) → Neon(데이터베이스)** 로 동작해요.

## 화면

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `/` | 누구나 | 공개된 앱 구경·플레이, 수료증 |
| `/login.html` | 누구나 | 로그인 / 학생 가입 (선생님도 여기서 로그인) |
| `/my.html` | 학생 | 내 앱 올리기·수정·삭제, 승인 상태 확인, 비밀번호 변경 |
| `/admin.html` | 선생님 | 승인·반려, 직접 올리기, 학생 계정 관리, 가입·공개 설정 |

## 처음 설정 (한 번만)

1. **Neon**: 프로젝트의 *Connection string* 을 복사해 둡니다. (표는 자동으로 만들어져서 SQL을 따로 실행할 필요가 없어요. 기존 데이터도 그대로 유지돼요.)
2. **Netlify → Site configuration → Environment variables** 에 추가:

   | 이름 | 필수 | 설명 |
   |---|---|---|
   | `DATABASE_URL` | ✅ | Neon 연결 문자열 |
   | `ADMIN_PASSWORD` | ✅ | **선생님 첫 비밀번호.** 관리자 계정이 없을 때 이 값으로 `admin` 계정을 한 번 만들어요 |
   | `ADMIN_USERNAME` | 선택 | 관리자 아이디 (기본 `admin`) |
   | `SESSION_SECRET` | 권장 | 아무 긴 문자열. 로그인 쿠키 서명용 (없으면 DATABASE_URL로 대신 만듦) |

3. GitHub에 push → Netlify가 자동 배포.
4. `/login.html` 에서 `admin` + `ADMIN_PASSWORD` 로 로그인 → **관리 화면 → 설정** 에서 **가입 코드**를 확인하고, 필요하면 바꾸세요.
   (관리자 비밀번호는 설정 탭에서 바꿀 수 있어요. 바꾼 뒤에는 `ADMIN_PASSWORD` 환경변수는 지워도 돼요.)
5. 학생에게 **사이트 주소 + 가입 코드**를 알려 주세요.

## 학생이 앱을 올리는 흐름

1. `/login.html` → 「처음이에요」에서 가입 코드·아이디·별명·비밀번호 입력 (별명은 '만든 친구'로 표시돼요. 실명 금지)
2. `/my.html` 에서 HTML 파일 선택 → **검사하기** → **올리기** (자동 보정·검사는 기존과 동일)
3. 기본 설정에서는 **「승인 대기」**. 선생님이 관리 화면에서 *해 보기 → 승인* 하면 갤러리에 나타나요. 반려하면 사유가 학생 화면에 보여요.
4. 학생이 승인된 앱을 고치면 다시 승인 대기가 돼요. (설정에서 **바로 공개**로 바꾸면 승인 없이 공개)
5. 수료증 기준 점수는 **선생님이** 관리 화면의 앱 「수정」에서 정해요. (학생은 정할 수 없어요)

## 선생님 설정 (관리 화면 → 설정)

- 학생 가입 허용 켜기/끄기, 가입 코드(비우면 누구나 가입), 새 코드 만들기
- 학생 업로드 **바로 공개 / 승인 후 공개**
- 학생 1명당 올릴 수 있는 앱 개수 (기본 3개 — Neon 무료 용량을 아끼려고)
- 학생이 고를 수 있는 주제 목록

## 계정 관리 (관리 화면 → 학생 계정)

- 선생님이 학생 계정을 대신 만들기 / **비밀번호 새로 정하기**(비밀번호를 잊은 학생) / 사용 중지 / 삭제
- 비밀번호를 바꾸거나 사용 중지하면 그 학생이 로그인해 둔 기기는 즉시 로그아웃돼요.
- 삭제할 때 그 학생의 앱을 남길지(선생님 소유로 이동) 함께 지울지 고를 수 있어요.

## 선생님 비밀번호를 잊었을 때

Neon → SQL Editor 에서 아래를 실행하고, Netlify 에 새 `ADMIN_PASSWORD` 를 넣어 **다시 배포**하면 그 비밀번호로 관리자 계정이 다시 만들어져요.

```sql
DELETE FROM users WHERE role = 'admin';
```

## 보안 메모

- 비밀번호는 scrypt로 해시해서 저장해요. 로그인은 HttpOnly 쿠키(7일), 5번 틀리면 5분 잠금.
- 학생이 올린 게임은 기존처럼 sandbox + CSP(`connect-src 'none'`)로 격리돼서 로그인 쿠키·서버에 접근할 수 없어요.
- 공개 전 앱은 올린 본인과 선생님만 미리 해 볼 수 있어요. 다른 학생의 앱은 고치거나 지울 수 없어요.
- 학생 계정에는 실명·이메일을 받지 않아요(아이디·별명·비밀번호만).

## 폴더 구조

```
index.html · play.html · certificate.html   갤러리/플레이/수료증 (기존)
login.html · my.html · admin.html           로그인·학생·교사 화면 (새로 추가/개편)
ui.css · site.js                            위 3개 화면의 공통 스타일·도우미
apps.json + 2026/…                          폴더로 올린 기존 앱 (그대로 동작)
netlify/functions/
  auth.mjs          가입·로그인·로그아웃·비밀번호 변경
  my.mjs            학생: 내 앱 목록/올리기/삭제
  admin.mjs         교사: 앱 승인·수정·삭제
  admin-users.mjs   교사: 학생 계정 + 설정
  apps.mjs · play.mjs  공개 목록 / 게임 본문(격리 헤더)
  _lib/             DB 연결·마이그레이션, 세션, 해시, 앱 검사·보정, 공통 저장 로직
```

## 아직 하지 않은 것

- **점수·수료 기록은 여전히 각 기기(브라우저)에 저장**돼요(`gallery-sdk.js`). 계정별 랭킹·수료 기록을 Neon에 저장하려면 다음 단계로 이어서 만들 수 있어요.
- 관리자 계정은 1개만 만들어져요(여러 교사가 필요하면 확장 가능).
