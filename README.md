# 우리 반 웹앱 갤러리

학생이 직접 가입하고, 자기가 만든 웹앱(HTML 파일 1개)을 올리고, 선생님이 확인해서 공개하는 갤러리예요.
**GitHub → Netlify(화면 + 서버 함수) → Neon(데이터베이스)** 로 동작해요.

## 화면

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `/` | 누구나 | 공개된 앱 구경·플레이, 수료증. 오른쪽 위에 **학생 로그인 · 회원가입 · 교사** 버튼 |
| `/login` (`/login.html`) | 학생 | 이메일로 로그인 / 회원가입(가입 코드 필요) |
| `/teacher` | 선생님 | 교사 로그인 → 관리 화면으로 이동 |
| `/my.html` | 학생 | 내 앱 올리기·수정·삭제, 승인 상태 확인, 비밀번호 변경 |
| `/admin.html` | 선생님 | 승인·반려, 직접 올리기, 학생 계정 관리, 가입·공개 설정 |

## 처음 설정 (한 번만)

1. **Neon**: 프로젝트의 *Connection string* 을 복사해 둡니다. (표는 자동으로 만들어져서 SQL을 따로 실행할 필요가 없어요. 기존 데이터도 그대로 유지돼요.)
2. **Netlify → Site configuration → Environment variables** 에 추가:

   | 이름 | 필수 | 설명 |
   |---|---|---|
   | `DATABASE_URL` | ✅ | Neon 연결 문자열 |
   | `ADMIN_PASSWORD` | ✅ | **선생님 첫 비밀번호.** 관리자 계정이 없을 때 이 값으로 `admin` 계정을 한 번 만들어요 |
   | `ADMIN_USERNAME` | 선택 | 관리자 아이디 (기본 `admin`) |
   | `SIGNUP_CODE` | 선택 | 학생 가입 코드의 **처음 값** (예: `0227`). 없으면 무작위로 만들어요. 이미 만들어진 뒤에는 관리 화면 설정에서 바꿔요 |
   | `SESSION_SECRET` | 권장 | 아무 긴 문자열. 로그인 쿠키 서명용 (없으면 DATABASE_URL로 대신 만듦) |

3. GitHub에 push → Netlify가 자동 배포.
4. 메인 화면의 **교사** 버튼(또는 `/teacher`)에서 `admin` + `ADMIN_PASSWORD` 로 로그인 → **관리 화면 → 설정** 에서 **가입 코드**를 확인하고, 필요하면 바꾸세요.
   (관리자 비밀번호는 설정 탭에서 바꿀 수 있어요. 바꾼 뒤에는 `ADMIN_PASSWORD` 환경변수는 지워도 돼요.)
5. 학생에게 **사이트 주소 + 가입 코드**를 알려 주세요.

## 학생이 앱을 올리는 흐름

1. 메인 화면의 **회원가입** 버튼 → 가입 코드·**이메일**·별명·비밀번호 입력 (별명은 '만든 친구'로 표시돼요. 실명 금지. 이메일은 로그인용이며 선생님만 볼 수 있어요)
2. `/my.html` 에서 HTML 파일 선택 → **검사하기** → **올리기** (자동 보정·검사는 기존과 동일)
3. 기본 설정에서는 **「승인 대기」**. 선생님이 관리 화면에서 *해 보기 → 승인* 하면 갤러리에 나타나요. 반려하면 사유가 학생 화면에 보여요.
4. 학생이 승인된 앱을 고치면 다시 승인 대기가 돼요. (설정에서 **바로 공개**로 바꾸면 승인 없이 공개)
5. 수료증 기준 점수는 **선생님이** 관리 화면의 앱 「수정」에서 정해요. (학생은 정할 수 없어요)

## 다양한 앱 올리기 (게임·퀴즈·학습·만들기·이야기)

- 올릴 때 **유형**을 고릅니다: 🎮게임 · ❓퀴즈 · 📚학습 · 🎨만들기 · 📖이야기 · ✨기타. 갤러리에는 유형 필터가 생기고, 카드에 유형이 표시돼요.
- **점수 기록(reportScore)은 게임만 필요**해요. 퀴즈·학습 등은 점수 없이 올려도 경고가 나오지 않고, 갤러리에서는 점수·수료증 없이 자유롭게 플레이해요. (퀴즈에도 선생님이 수료 기준을 정해 주면 수료증을 줄 수 있어요.)
- 학생 화면 **「💡 무엇을 만들어 볼까요?」**에서 유형을 고르면 아이디어와 *AI에게 보낼 요청 글*이 유형에 맞게 만들어져요(퀴즈용은 점수 코드를 빼고, 게임용은 점수 코드를 포함).
- 기존 앱은 모두 「게임」으로 처리돼요. `apps.json`의 앱에 `"kind": "퀴즈"`를 적으면 유형을 바꿀 수 있어요.

## 댓글(피드백)과 수정 요청

- 갤러리의 **모든 앱 카드에서 「플레이」 버튼 옆 「💬 의견」 버튼**을 누르면 의견 창이 열려요. 학생이 올린 앱은 플레이 화면 옆에 창이 펼쳐지고, `apps.json`으로 올린 기존 앱은 전용 의견 페이지(`feedback.html`)가 열려요. 플레이 화면 오른쪽 위에도 「💬 의견」 버튼이 있어요. 종류: 🛠수정 요청 · ❓질문 · 👏칭찬·응원. (로그인하지 않은 방문자는 읽거나 쓸 수 없어요.)
- 제작자는 **내 앱** 화면에서 「고쳐 달라는 의견 N건」 알림을 보고, 고친 뒤 **「✓ 반영했어요」**를 누르고 답글을 남겨요.
- 선생님도 승인 전(대기 중) 앱에 의견을 남길 수 있고, 올린 학생에게만 보여요. 선생님은 모든 의견을 삭제할 수 있고, 학생은 자기 의견만 지울 수 있어요.
- 의견에는 작성자의 **별명만** 표시돼요(이메일 비공개). 한 사람이 앱 하나에 10개까지, 300자까지 쓸 수 있어요.
- 앱을 삭제하거나 학생 계정을 삭제하면 관련 의견도 함께 지워져요.
- 폴더 앱(`apps.json`)에는 제작자 계정이 없어서 「반영했어요」 표시는 선생님만 할 수 있어요.

## 학생 한꺼번에 가입 (엑셀)

관리 화면 → **학생 계정** → 「엑셀로 학생 한꺼번에 가입시키기」

1. **양식 내려받기(.xlsx)** → 이메일·별명을 채워요. 비밀번호는 비우면 8자 임시 비밀번호가 자동으로 만들어져요. (제목 줄은 그대로 두면 열 순서가 달라도 찾아 줘요.)
2. 파일(.xlsx 또는 .csv)을 올리면 **미리보기**에서 문제 있는 줄(이메일 형식·중복·짧은 비밀번호)이 표시되고, 가입 가능한 학생만 가입돼요.
3. 가입이 끝나면 **「결과 내려받기(.xlsx)」**로 임시 비밀번호가 담긴 명단을 저장해 학생에게 나눠 주세요. 비밀번호는 그 화면에서만 볼 수 있어요.

엑셀 파일은 브라우저 안에서 읽어요(별도 프로그램·인터넷 연결 불필요). 구버전 `.xls`는 `.xlsx`로 저장해서 올려 주세요. 한 번에 수백 명도 30명씩 나눠 자동으로 처리해요.

## 선생님 설정 (관리 화면 → 설정)

설정은 ①학생 가입 ②학생이 올린 앱 ③주제 목록 세 칸으로 나뉘어 있고, 아래쪽에 **저장 바**가 항상 보여요. 값을 바꾸면 바가 노랗게 바뀌며 「변경사항 저장」이 켜지고, 「되돌리기」로 취소할 수 있어요. 저장하지 않고 다른 탭으로 가려 하면 확인창이 떠요.

- 학생 가입 허용 켜기/끄기, 가입 코드(비우면 누구나 가입), 새 코드 만들기
- 학생 업로드 **바로 공개 / 승인 후 공개**
- 학생 1명당 올릴 수 있는 앱 개수 (기본 3개 — Neon 무료 용량을 아끼려고)
- 학생이 고를 수 있는 주제 목록

## 계정 관리 (관리 화면 → 학생 계정)

- 선생님이 학생 계정을 대신 만들기 / **비밀번호 새로 정하기**(비밀번호를 잊은 학생) / 사용 중지 / 삭제
- 비밀번호를 바꾸거나 사용 중지하면 그 학생이 로그인해 둔 기기는 즉시 로그아웃돼요.
- 삭제할 때 그 학생의 앱을 남길지(선생님 소유로 이동) 함께 지울지 고를 수 있어요.

## 선생님 비밀번호를 잊었을 때

Neon → SQL Editor 에서 아래를 실행하고, Netlify 에 새 `ADMIN_PASSWORD` 를 넣어 **다시 배포**하면 그 비밀번호로 관리자 계정이 다시 만들어져요.

```sql
DELETE FROM users WHERE role = 'admin';
```

## 보안 메모

- 비밀번호는 scrypt로 해시해서 저장해요. 로그인은 HttpOnly 쿠키(7일), 5번 틀리면 5분 잠금.
- 학생이 올린 게임은 기존처럼 sandbox + CSP(`connect-src 'none'`)로 격리돼서 로그인 쿠키·서버에 접근할 수 없어요.
- 공개 전 앱은 올린 본인과 선생님만 미리 해 볼 수 있어요. 다른 학생의 앱은 고치거나 지울 수 없어요.
- 학생 계정에는 이메일·별명·비밀번호만 저장해요. 이메일은 **인증하지 않고** 메일도 보내지 않아요(로그인 아이디 용도). 그래서 비밀번호를 잊으면 선생님이 새로 정해 줘요.

## 폴더 구조

```
index.html · play.html · certificate.html   갤러리/플레이/수료증 (기존)
login.html · my.html · admin.html           로그인·학생·교사 화면 (새로 추가/개편)
ui.css · site.js                            위 3개 화면의 공통 스타일·도우미
xlsx-lite.js                                엑셀(.xlsx)·CSV 읽기/쓰기 (외부 라이브러리 없음)
feedback.html                               기존(폴더) 앱의 의견 전용 페이지
comments.js                                 댓글 창 (플레이·내 앱 화면이 함께 사용)
apps.json + 2026/…                          폴더로 올린 기존 앱 (그대로 동작)
netlify/functions/
  auth.mjs          가입·로그인·로그아웃·비밀번호 변경
  comments.mjs      댓글(피드백): 목록·작성·반영 표시·삭제
  my.mjs            학생: 내 앱 목록/올리기/삭제
  admin.mjs         교사: 앱 승인·수정·삭제
  admin-users.mjs   교사: 학생 계정 + 설정
  apps.mjs · play.mjs  공개 목록 / 게임 본문(격리 헤더)
  _lib/             DB 연결·마이그레이션, 세션, 해시, 앱 검사·보정, 공통 저장 로직
```

## 아직 하지 않은 것

- **점수·수료 기록은 여전히 각 기기(브라우저)에 저장**돼요(`gallery-sdk.js`). 계정별 랭킹·수료 기록을 Neon에 저장하려면 다음 단계로 이어서 만들 수 있어요.
- 관리자 계정은 1개만 만들어져요(여러 교사가 필요하면 확장 가능).
